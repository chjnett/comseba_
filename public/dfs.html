8방향 좌표계 읽는 법

재귀 안에서도 현재 칸을 둘러싼 8칸 전부를 순서대로 확인해야 한다. 아래 3×3 표에서 가운데가 현재 칸 (r, c), 나머지 8칸이 각각의 (dr, dc) 오프셋이다.

↖왼쪽위(-1,-1)
↑위(-1,0)
↗오른쪽위(-1,1)
←왼쪽(0,-1)
●현재 칸(r, c)
→오른쪽(0,1)
↙왼쪽아래(1,-1)
↓아래(1,0)
↘오른쪽아래(1,1)

4방향 문제였다면 이 중 ↑↓←→ 4칸만 확인했겠지만, 이 문제는 8칸 전부를 확인한다. 그래서 방향 배열도 4개가 아니라 8개가 필요하다:

int dr[8] = {-1,-1,-1, 0,0, 1,1,1};
int dc[8] = {-1, 0, 1,-1,1,-1,0,1};

코드로 옮기기

위 시뮬레이터의 훑기와 파고들기가 실제 코드의 어느 부분과 대응하는지 보자. 별도의 자료구조를 쓰지 않고 함수 본체(dfs())가 스스로를 호출한다.

훑기 — 다음 호수 칸 찾기 
int lakeCount = 0;
for (int i = 0; i < h; i++) {
    for (int j = 0; j < w; j++) {
        if (board[i][j] == 'L' && !visited[i][j]) {
            dfs(i, j);   // 새 호수 발견, 탐사 시작
            lakeCount++;
        }
    }
}
파고들기 — 자료구조 없는 순수 재귀 (8방향) 
int dr[8] = {-1,-1,-1, 0,0, 1,1,1};
int dc[8] = {-1, 0, 1,-1,1,-1,0,1};

void dfs(int r, int c) {
    visited[r][c] = true;

    for (int d = 0; d < 8; d++) {
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (nr < 0 || nr >= h || nc < 0 || nc >= w) continue;
        if (visited[nr][nc]) continue;
        if (board[nr][nc] != 'L') continue;

        dfs(nr, nc);   // 여기서 바로 다음 칸으로 "타고 들어감"
    }
}
