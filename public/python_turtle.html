2. 거북이와 함께 기초 문법 탐험

파이썬의 가장 중요한 규칙들을 거북이와 함께 놀면서 알아봐요! 모든 거북이 프로그램은 거북이를 불러오는 이 코드로 시작해요. 

import turtle
t = turtle.Turtle()
# ... 여기에 거북이 명령을 적어요 ...
turtle.done()  # 맨 마지막에는 꼭 이 코드를 넣어요!

📦 2-1. 변수 (Variable): "이름표가 붙은 상자"

핵심 문법: 변수 할당 연산자 (=)

방금 쓴 t = turtle.Turtle()에서 t는 뭘까요? 거북이를 담아둔 상자의 이름표예요.

  • 파이썬에서는 = 기호로 오른쪽에 있는 것(새 거북이)을 왼쪽 상자(t)에 넣어요.
  • 그래서 앞으로는 "어이, 거북아!" 라고 부르지 않고, 짧게 "t야!" 라고 부르면 된답니다.

🚶 2-2. 함수 (Function): "거북이에게 내리는 명령"

핵심 문법: 메서드 호출과 매개변수

상자 안에 있는 t 거북이에게 움직이라고 명령(함수)을 내릴 때는 점(.)을 찍고 괄호 ()를 써요.

t.forward(100)  # 앞으로 100만큼 가!
t.left(90)      # 왼쪽으로 90도 돌아!
  • t.forward()는 "t야, 앞으로 가!"라는 뜻이에요.
  • 괄호 (100) 안의 숫자는 얼마나 많이 갈지 알려주는 중요한 쪽지(매개변수)랍니다.

🅰️ 2-3. 자료형 (Data Type): "숫자와 글자의 차이"

핵심 문법: 정수(int)와 문자열(str)

컴퓨터는 숫자와 글자를 다르게 취급해요. 거북이에게 숫자를 줄 때와 글자를 줄 때의 차이를 보세요!

t.forward(100)         # 숫자: 따옴표 없이 그냥 써요.
t.write("안녕 파이썬!") # 글자: 반드시 따옴표(" ")를 입혀줘야 해요!
  • 숫자(100)는 계산할 수 있어서 따옴표 없이 써요.
  • 글자("안녕 파이썬!")는 컴퓨터가 "이건 그냥 읽는 글자구나" 하고 알 수 있게 꼭 따옴표 옷을 입혀줘야 한답니다!
🔁

3. 더 똑똑하게 명령하기: 반복과 리스트

🪄 3-1. 반복문 (for): "얍얍얍 마법 주문"

핵심 문법: for 반복문과 들여쓰기(Indentation)

같은 동작을 여러 번 하고 싶을 때, 파이썬은 들여쓰기(띄어쓰기 4칸)로 묶어서 마법 주문을 만들어요.

for i in range(4):    # 4번 반복해! (여기 끝에 콜론(:) 꼭 쓰기)
    t.forward(100)    # 꼭 띄어쓰기 4칸!
    t.right(90)       # 꼭 띄어쓰기 4칸!
  • for i in range(4): 는 "자, 지금부터 4번 반복한다!" 라는 주문이에요.
  • 파이썬에서는 이 주문의 영향을 받는 명령들을 꼭 띄어쓰기 4칸을 해서 묶어줘야 해요. 안 그러면 컴퓨터가 헷갈려요! (이걸 들여쓰기라고 불러요)

🎒 3-2. 리스트 (List): "한 상자에 여러 개 담기"

핵심 문법: 리스트(List)와 인덱스

여러 가지 색깔 크레파스를 한 상자에 모아두려면 대괄호 [ ] 를 써요.

colors = ["red", "yellow", "blue"]
t.color(colors[0])  # 빨간색을 꺼내요!
  • colors라는 상자에는 3가지 색이 들어있어요.
  • 재밌는 건, 컴퓨터는 숫자를 0번부터 센다는 사실! 그래서 0번을 꺼내면 첫 번째인 "red"가 나와요.
⭐

4. 거북이 그래픽 프로젝트 (놀면서 배우기)

지금까지 배운 변수, 자료형(숫자와 글자), 반복문을 사용해서 멋진 그림을 그려봐요!
각 프로젝트는 새 .py 파일로 만들어서 ▶ (실행) 버튼을 누르면 화면에 그림 창이 뜹니다.

🟢 프로젝트 1. 네모 그리기 (기본 명령 반복하기)

import turtle
t = turtle.Turtle()     # 변수 t에 거북이 담기

t.forward(100)          # 숫자(int)로 길이 명령
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)

turtle.done()

→ "똑같은 코드가 너무 길지? 바로 이럴 때 마법 주문(반복문)이 필요해!"

🟡 프로젝트 2. 반복문으로 네모 그리기 (for문 활용)

import turtle
t = turtle.Turtle()
t.color("blue")         # 글자(문자열)로 색깔 지정! 꼭 따옴표 쓰기
t.pensize(3)

for i in range(4):      # 4번 반복하는 마법 주문
    t.forward(100)      # 띄어쓰기 4칸!
    t.right(90)         # 띄어쓰기 4칸!

turtle.done()

→ 코드가 훨씬 짧아졌죠? 아이에게 range(4)를 range(5)로, right(90)을 right(144)로 숫자만 직접 바꿔보게 하세요. (그러면 별이 그려져요!)

🟠 프로젝트 3. 무지개 나선 그리기 (리스트 활용)

import turtle
t = turtle.Turtle()
t.speed(0)
t.pensize(3)

# 리스트(상자 묶음)에 여러 글자(색깔) 담기
colors = ["red", "orange", "yellow", "green", "blue", "purple"]

for i in range(60):       # 무려 60번이나 반복!
    t.color(colors[i % 6])  # 리스트 안의 색을 순서대로 꺼내 써요
    t.forward(i * 3)        # 갈수록 길이가 길어져요!
    t.right(59)

turtle.done()

→ 알록달록 소용돌이가 그려져서 아이들이 제일 좋아하는 프로젝트예요. 리스트 colors에 원하는 다른 영어 색깔을 추가해 보세요.

🎁 프로젝트 4. 완성작 — 나만의 이름 그림 (문자열 출력)

import turtle
t = turtle.Turtle()
t.speed(0)

# 배경에 금색 별 그리기
t.color("gold")
for i in range(5):
    t.forward(100)
    t.right(144)

# 가운데로 이동해서 문자열 쓰기
t.penup()
t.goto(-100, -20)
t.pendown()
t.color("purple")

# "민준이의 그림" 이라는 '글자(문자열)'를 적어요
t.write("민준이의 그림", font=("Arial", 24, "bold"))

turtle.done()

→ 이 코드를 열어서 "민준이의 그림" 부분을 아이의 이름으로 바꾸게 해주세요. 글자니까 따옴표("")를 실수로 지우지 않게 조심하세요!

5. 에러 대처법 (컴퓨터의 말 알아듣기)

컴퓨터는 규칙을 아주 꼼꼼하게 따져서, 하나라도 틀리면 빨간 글씨(에러)로 알려줘요. 이건 실패가 아니라 "여기를 고쳐줘!"라는 뜻이에요.

에러 메시지어떤 문법을 틀렸을까?해결 방법
NameError변수나 함수 이름을 잘못 부름 (오타)철자를 다시 확인하세요 (예: turtel → turtle)
SyntaxError문자열의 따옴표나 괄호를 빼먹음글자 양쪽에 " "가 잘 있는지 확인하세요.
IndentationError반복문(for)의 들여쓰기가 틀림for 문 아래 줄의 명령어들이 4칸 띄어쓰기가 잘 되었는지 확인하세요.
