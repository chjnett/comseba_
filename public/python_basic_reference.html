SETUP GUIDE

파이썬 & VS Code 설치 방법 (Windows / Mac)

개인 컴퓨터에서 직접 파이썬 코드를 작성하고 실행할 수 있도록 개발 환경을 구성해 봅시다. 가장 인기 있는 코드 에디터인 VS Code (Visual Studio Code)와 파이썬(Python)의 OS별 설치 가이드입니다.

🪟 Windows (윈도우) 개발 환경 구성

1단계. 파이썬 설치
  1. 공식 웹사이트 (python.org)의 Downloads 페이지로 접속합니다.
  2. 노란색 Download Python 3.x.x 버튼을 눌러 설치 프로그램을 받습니다.
  3. 다운로드한 .exe 파일을 실행합니다.
  4. ⚠️ 필독: 설치 창 아래쪽의 "Add python.exe to PATH" 체크박스를 반드시 체크해야 합니다. (체크하지 않으면 명령 프롬프트에서 파이썬 명령어를 인식하지 못합니다.)
  5. Install Now를 클릭해 설치를 진행합니다.
2단계. VS Code 설치
  1. 공식 웹사이트 (code.visualstudio.com)로 접속합니다.
  2. Download for Windows를 눌러 인스톨러를 다운로드한 후 실행합니다.
  3. 설치 도중 추가 작업 선택 항목에서 "PATH에 추가"가 체크되어 있는지 확인하고 완료합니다.
3단계. 확장 프로그램 설치 및 확인
  1. VS Code를 열고 왼쪽 탭의 블록 모양 아이콘(Extensions, 단축키 Ctrl+Shift+X)을 클릭합니다.
  2. 검색창에 Python을 입력하여 Microsoft에서 제공하는 공식 플러그인을 설치(Install)합니다.
  3. 새 파일(hello.py)을 만들고 print("hello") 작성 후 우측 상단의 ▶ (Run File)을 눌러 실행 결과를 확인합니다.

🍎 macOS (맥) 개발 환경 구성

1단계. 파이썬 설치
  1. 공식 웹사이트 (python.org)의 Downloads - macOS 페이지로 접속합니다.
  2. 최신 Stable 버전의 macOS 64-bit universal2 installer 패키지(.pkg)를 다운로드해 실행합니다.
  3. 설치 단계에 따라 패스워드를 입력하여 완료합니다.
  4. 설치 완료 후 생성되는 폴더 내 "Install Certificates.command" 파일을 꼭 더블클릭해 실행해주세요. (SSL 인증서 패치로 라이브러리 설치 실패를 예방합니다.)
2단계. VS Code 설치
  1. 공식 웹사이트 (code.visualstudio.com)로 접속합니다.
  2. Download for Mac을 눌러 ZIP 압축 파일을 다운로드합니다.
  3. 다운로드된 ZIP 파일의 압축을 해제한 후, 생성된 Visual Studio Code.app 파일을 응용 프로그램 (Applications) 폴더로 직접 드래그앤드롭하여 이동합니다.
3단계. 터미널 환경 설정 및 연동
  1. VS Code를 열고 단축키 Cmd+Shift+P를 눌러 명령 팔레트를 엽니다.
  2. shell command 입력 후 "Shell Command: Install 'code' command in PATH"를 선택해 설치합니다.
  3. 왼쪽 Extensions 탭(Cmd+Shift+X)에서 Microsoft의 공식 Python 플러그인을 설치합니다.
  4. 이제 터미널에서 code . 명령으로 에디터를 실행하거나, VS Code 우측 상단 ▶ 재생 버튼으로 파이썬 코드를 실행할 수 있습니다.
