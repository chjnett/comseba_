지뢰는 왜
이렇게 퍼질까?

지뢰찾기에서 빈 칸을 클릭하면, 그 칸 하나만 열리는 게 아니라 안전한 영역 전체가 한 번에 열린다. 대체 어디까지 퍼지고, 어디서 멈추는 걸까? 코드업 3500번의 실제 예제(9×9, 정답 그대로)를 한 칸씩 따라가며 BFS가 언제 계속 나아가고, 언제 멈추는지 살펴보는 기록이다.

1은 지뢰, 0은 빈 칸이다. 아직 열지 않은 칸은 화면에 _로 표시된다. (r, c) 좌표를 하나 클릭했을 때, 화면에 어디까지 열리는지를 구하는 문제다.

4024(호수 세기)와 다른 점: 이번엔 칸이 처음부터 "물"인지 알 수 없다. 칸을 열어봐야만 그 칸 주변에 지뢰가 몇 개인지 알 수 있고, 그 결과(0인지 아닌지)에 따라 계속 퍼질지 멈출지가 결정된다.

코드로 옮기기

지금 시뮬레이터가 어느 단계인지에 따라 아래 블록 중 하나가 밝아진다. 맨 처음 클릭 판정과, 그 이후 반복되는 확산 로직이 나뉘어 있다.

시작 — 클릭한 칸이 지뢰인지 확인 
if (mapv[r][c] == 1) {
    shown[r][c] = true;
    value[r][c] = -1;       // 지뢰 클릭 → 여기서 끝
} else {
    queue.push({r, c});
    shown[r][c] = true;       // 안전 → 확산 시작
}
확산 — 값이 0일 때만 계속 퍼짐 
while (!queue.empty()) {
    auto [r, c] = queue.front(); queue.pop();

    int cnt = countMines(r, c);   // 주변 8칸 지뢰 수
    value[r][c] = cnt;

    if (cnt == 0) {                // 0이면: 계속 퍼짐
        for (int d = 0; d < 8; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr<0||nr>=9||nc<0||nc>=9) continue;
            if (shown[nr][nc]) continue;
            shown[nr][nc] = true;
            queue.push({nr, nc});
        }
    }
    // cnt > 0 이면: 아무것도 안 하고 넘어감 (멈춤)
}
