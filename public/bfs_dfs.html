8방향 좌표계 읽는 법

4방향 문제에서 방향이 4개였다면, 대각선까지 포함할 땐 현재 칸을 둘러싼 8칸 전부를 확인해야 단다. 아래 3×3 표에서 가운데가 현재 칸 (r, c), 나머지 8칸이 각각의 (dr, dc) 오프셋이다.

↖왼쪽위(-1,-1)
↑위(-1,0)
↗오른쪽위(-1,1)
←왼쪽(0,-1)
●현재 칸(r, c)
→오른쪽(0,1)
↙왼쪽아래(1,-1)
↓아래(1,0)
↘오른쪽아래(1,1)

4방향 문제였다면 이 중 ↑↓←→ 4칸만 확인했겠지만, 이 문제는 8칸 전부를 확인한다. 그래서 방향 배열도 4개가 아니라 8개가 필요하다:

int dr[8] = {-1,-1,-1, 0,0, 1,1,1};
int dc[8] = {-1, 0, 1,-1,1,-1,0,1};

코드로 옮기기

위 시뮬레이터의 두 동작이 실제 코드의 어느 부분과 대응하는지 보자. 지금 시뮬레이터가 어느 단계인지에 따라 아래 블록 중 하나가 밝아진다.

훑기 — 다음 호수 칸 찾기 
int lakeCount = 0;
for (int i = 0; i < h; i++) {
    for (int j = 0; j < w; j++) {
        if (board[i][j] == 'L' && !visited[i][j]) {
            bfs(i, j);   // 새 호수 발견, 탐사 시작
            lakeCount++;
        }
    }
}
꺼내기 — BFS로 호수 전체 방문 (8방향) 
int dr[8] = {-1,-1,-1, 0,0, 1,1,1};
int dc[8] = {-1, 0, 1,-1,1,-1,0,1};

void bfs(int sr, int sc) {
    queue.push({sr, sc});
    visited[sr][sc] = true;

    while (!queue.empty()) {
        auto [r, c] = queue.front(); queue.pop();

        for (int d = 0; d < 8; d++) {   // 4 -> 8
            int nr = r + dr[d], nc = c + dc[d];
            if (nr<0 || nr>=h || nc<0 || nc>=w) continue;
            if (visited[nr][nc] || board[nr][nc]!='L') continue;

            visited[nr][nc] = true;
            queue.push({nr, nc});
        }
    }
}
