01 변수·입출력·자료형

입출력 — 코스프로 채점 환경의 기본

# 한 줄에 정수 하나
n = int(input())

# 한 줄에 공백으로 구분된 정수 여러 개
a, b = map(int, input().split())

# 한 줄에 공백 구분 정수 N개 → 리스트로

Tip 코스프로는 보통 함수 안에 코드를 작성하는 함수형 문제가 많습니다. input()으로 직접 입력받는 형식인지, def solution(...) 안에 로직만 채우는 형식인지 문제 설명을 먼저 확인하세요.

리스트 컴프리헨션 — 코스프로 단골 문법

리스트 컴프리헨션(List Comprehension)은 기존 리스트나 반복 가능한(iterable) 객체를 기반으로 새로운 리스트를 쉽고 빠르게 만드는 방법입니다. 코스프로 시험에서 코드 한 줄로 빈번히 활용되는 핵심 문법입니다.

# 1. 기본 구조: [표현식 for 항목 in 반복가능객체]
squares = [x**2 for x in range(1, 11)]
# 결과: [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

# 2. 필터링 (if 사용): [표현식 for 항목 in 반복가능객체 if 조건식]
# arr에서 짝수만 골라내기
arr = [1, 2, 3, 4, 5, 6]
evens = [x for x in arr if x % 2 == 0]
# 결과: [2, 4, 6]

# 3. 조건부 표현식 (if-else 사용): [참일때_값 if 조건식 else 거짓일때_값 for 항목 in 반복가능객체]
# 홀수는 'odd', 짝수는 'even'으로 변환
parity = ['even' if x % 2 == 0 else 'odd' for x in arr]
# 결과: ['odd', 'even', 'odd', 'even', 'odd', 'even']

# 4. 2차원 리스트(N x M) 초기화 (m열, n행)
grid = [[0] * m for _ in range(n)]
자주 하는 실수 2차원 리스트를 [[0]*m] * n으로 만들면 안의 모든 행 리스트가 동일한 메모리 주소를 참조하게 됩니다. 따라서 grid[0][0] = 1을 실행했을 때 모든 행의 첫 번째 열 값이 동시에 1로 변하는 치명적인 버그가 발생합니다. 반드시 [[0]*m for _ in range(n)] 형태로 행마다 독립된 리스트 객체를 생성하세요.

컴프리헨션을 활용한 문제 풀이 패턴

패턴 A. 조건 필터링 후 합계/평균 구하기

문제: 시험 점수 리스트 scores가 주어질 때, 과락 기준인 60점 이상인 점수들만의 평균을 구하세요.

scores = [55, 80, 92, 45, 70, 60]

# 60점 이상인 점수만 리스트 컴프리헨션으로 필터링
passed = [s for s in scores if s >= 60] # [80, 92, 70, 60]
average = sum(passed) / len(passed)
print(average) # 75.5

문제: 알파벳 소문자 문자열 s에서 모음(a, e, i, o, u)을 모두 제거한 문자열을 반환하세요.

# 모음이 아닌 문자들만 모아서 리스트로 만든 뒤 join

05 딕셔너리 & 집합

딕셔너리 — "개수 세기" 문제의 핵심 도구

cnt = {}
for ch in 'banana':
    cnt[ch] = cnt.get(ch, 0) + 1
# {'b':1, 'a':3, 'n':2}

for key, value in cnt.items():
    print(key, value)

if 'a' in cnt:        # 키 존재 여부 확인 (O(1)로 빠름)
    print('있음')
Tip collections.Counter를 쓰면 위 카운팅을 한 줄로 줄일 수 있습니다: from collections import Counter; cnt = Counter('banana'). 코스프로 채점 환경에서 표준 라이브러리는 대부분 허용되니 적극 활용하세요.

집합(set) — 중복 제거 & 빠른 포함 여부 확인

06 함수와 재귀

def add(a, b=0):       # b는 기본값(default argument)
    return a + b

add(3)             # 3  (b는 기본값 0 사용)
add(3, 5)          # 8

재귀 함수 — 코스프로 3급 단골 유형

def factorial(n):
    if n <= 1:          # 종료 조건(base case) — 반드시 필요
        return 1
    return n * factorial(n - 1)

factorial(5)   # 120
Tip 재귀 함수를 짤 때는 ① 종료 조건(언제 멈추는가), ② 더 작은 문제로 줄이는 식(n → n-1), 이 두 가지만 정확히 정의하면 됩니다. 종료 조건을 빼먹으면 RecursionError가 발생합니다.

람다(Lambda) 함수 — 한 줄짜리 익명 함수

이름을 지어 정의(def)하지 않고, 필요한 곳에서 한 줄로 즉석 정의해서 쓰는 익명 함수(Anonymous Function)입니다.

# 문법: lambda 매개변수: 표현식
add_lambda = lambda x, y: x + y
print(add_lambda(3, 5))  # 8

람다 함수는 단독으로 쓰기보다는, 주로 내장 함수의 기준(key)을 지정할 때(예: sorted(), min(), max()) 극도로 유용합니다.

# 예제 1: 튜플 리스트에서 2번째 값(점수)을 기준으로 오름차순 정렬
students = [("철수", 85), ("영희", 92), ("민수", 78)]
students.sort(key=lambda x: x[1])
print(students)  # [('민수', 78), ('철수', 85), ('영희', 92)]

# 예제 2: map()과 조합하여 리스트의 모든 원소 제곱하기
nums = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, nums))
print(squared)   # [1, 4, 9, 16]
💡 다중 조건 정렬(Multi-key Sorting) 팁 람다에 튜플 (기준1, ... )을 반환하도록 설정하면 1차 기준이 동일할 때 2차 기준으로 정렬할 수 있습니다. 수치형 데이터에 -를 붙이면 내림차순(역순)이 됩니다. 
# 1차 기준: 점수 내림차순 (-x[1]), 2차 기준: 이름 오름차순 (x[0])
students.sort(key=lambda x: (-x[1], x[0]))

07 문자열 유형 정리

회문(팰린드롬) 판별 단골

def is_palindrome(s):
    return s == s[::-1]

슬라이싱으로 뒤집은 문자열과 원본을 그대로 비교하는 게 가장 빠른 방법입니다.

아나그램(애너그램) 판별

def is_anagram(a, b):
    return sorted(a) == sorted(b)

두 문자열을 정렬해서 같은지 비교하면 글자 구성이 같은지 바로 알 수 있습니다.

문자 빈도수 세기

cnt = {}
for ch in s:
    cnt[ch] = cnt.get(ch,0)+1

딕셔너리로 카운팅 → "가장 많이 등장한 문자" 같은 후속 질문에 바로 활용 가능.

문자열 압축/패턴 찾기

# 연속된 같은 문자 개수 세기
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j]==s[i]:
        j += 1
    # s[i]가 (j-i)번 연속됨
    i = j

"두 개의 포인터(i, j)로 같은 구간의 끝을 찾는다"는 패턴은 문자열 압축 문제의 기본 틀입니다.

08 배열/리스트 유형 정리

누적합(Prefix Sum) 단골

prefix = [0] * (len(arr)+1)
for i in range(len(arr)):
    prefix[i+1] = prefix[i] + arr[i]
# 구간 [l,r) 합 = prefix[r] - prefix[l]

"특정 구간의 합을 여러 번 물어보는" 문제에서 매번 더하면 느립니다. 미리 누적합을 만들어두면 구간 합을 O(1)에 구합니다.

투 포인터(Two Pointer)

l, r = 0, len(arr)-1
while l < r:
    if arr[l]+arr[r] == target:
        break
    elif arr[l]+arr[r] < target:
        l += 1
    else:
        r -= 1

정렬된 배열에서 "합이 특정 값이 되는 두 수 찾기" 같은 문제를 O(N)에 풉니다.

슬라이딩 윈도우

# 길이 k인 구간의 최대 합
window = sum(arr[:k])
best = window
for i in range(k, len(arr)):
    window += arr[i] - arr[i-k]
    best = max(best, window)

구간이 한 칸씩 이동할 때 "빠지는 값 빼고 들어오는 값 더하기"만 하면 매번 새로 합을 구할 필요가 없습니다.

2차원 리스트 순회

for i in range(n):
    for j in range(m):
        print(grid[i][j])

행렬/격자 문제는 거의 항상 이중 for문이 기본 틀이며, 상/하/좌/우 이동은 dx,dy 방향 벡터 리스트로 처리하면 코드가 짧아집니다.

09 시뮬레이션 유형 정리

"문제에서 설명한 규칙을 그대로, 단계별로 코드로 옮기면 풀리는" 유형입니다. 코스프로 2~3급에서 비중이 큽니다.

1. 상태(State) 정의하기

위치, 방향, 점수, 남은 횟수 등 "지금 무엇이 바뀌고 있는지"를 변수로 먼저 정의합니다.

2. 한 단계(틱)의 동작을 함수/블록으로 분리

이분 탐색(Binary Search)

def binary_search(arr, target):
    lo, hi = 0, len(arr)-1
    while lo <= hi:
        mid = (lo+hi)//2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid+1
        else:
            hi = mid-1
    return -1          # 못 찾음

# 표준 라이브러리로 간단히 — 정렬된 배열 전용

11 이 레벨에서 나오는 알고리즘 정리

알고리즘한 줄 설명시간복잡도
완전탐색가능한 모든 경우를 다 확인대개 O(N²)~O(N!) — 입력 크기 작을 때만
그리디(탐욕법)매 순간 가장 좋아 보이는 선택을 함O(N) ~ O(N log N)
정렬 후 처리먼저 정렬하면 문제가 쉬워지는 패턴O(N log N)
이분 탐색정렬된 데이터에서 절반씩 줄여가며 탐색O(log N)
두 포인터 / 슬라이딩 윈도우구간을 양 끝/한쪽씩 옮기며 탐색O(N)
재귀 / 간단한 DP(메모이제이션)큰 문제를 같은 모양의 작은 문제로 나눠서 풀기문제별로 다름
BFS/DFS 기초그래프·격자를 너비/깊이 우선으로 탐색 (3급 후반~상위 단계에 등장)O(N+E)

그리디 예시 — 동전 거스름돈

coins = [500, 100, 50, 10]
amount = 1260
count = 0
for c in coins:
    count += amount // c
    amount %= c
print(count)   # 가장 큰 동전부터 최대한 많이 사용

간단한 DP 예시 — 피보나치 (메모이제이션)

memo = {}
def fib(n):
    if n <= 1:
        return n
    if n in memo:        # 이미 계산했으면 재사용
        return memo[n]
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]

단순 재귀로 피보나치를 풀면 같은 값을 계속 다시 계산해서 느려집니다. memo 딕셔너리에 결과를 저장해두고 재사용하는 것이 "메모이제이션"이며, DP의 가장 쉬운 형태입니다.

12 자주 하는 실수 체크리스트

  • 2차원 리스트를 [[0]*m]*n으로 만들어서 모든 줄이 같은 객체를 참조하는 실수
  • 인덱스가 범위를 벗어나는지(경계 체크) 확인하지 않고 배열에 접근
  • 문자열을 인덱스로 직접 수정하려는 시도 (문자열은 불변 — list로 바꿔서 작업)
  • 정렬되지 않은 배열에 이분 탐색을 적용
  • arr.sort()(반환값 없음)와 sorted(arr)(새 리스트 반환)를 혼동
  • 재귀 함수에 종료 조건(base case)을 빼먹어 무한 재귀 발생
  • 나눗셈에서 /(실수 나눗셈)와 //(정수 나눗셈)를 혼동
  • 입력 형식(한 줄 정수 vs 공백 구분 여러 값 vs 함수형 매개변수)을 잘못 파악

2. 탐색 및 그래프 알고리즘 (Search & Graph)

BFS (너비 우선 탐색) 빈출

개념: 큐(Queue)를 이용하여 시작점부터 인접한 노드를 레벨별로 탐색합니다.

💡 키워드: 최단 거리(가중치 없는 그래프), 미로 탈출 최단 칸수.

🐍 Python
from collections import deque
def bfs(graph, start, visited):
    q = deque([start])
    visited[start] = True
    while q:
        v = q.popleft()
        for i in graph[v]:
            if not visited[i]:
                q.append(i)
                visited[i] = True
🟦 C++
#include <queue>
#include <vector>

void bfs(int start, const std::vector<std::vector<int>>& graph, std::vector<bool>& visited) {
    std::queue<int> q;
    q.push(start); visited[start] = true;
    while(!q.empty()) {
        int v = q.front(); q.pop();
        for(int next : graph[v]) {
            if(!visited[next]) {
                q.push(next); visited[next] = true;
            }
        }
    }
}

개념: 재귀 호출이나 스택을 이용하여 가능한 깊숙이 들어가 탐색한 뒤 되돌아옵니다.

💡 키워드: 모든 경로 탐색, 사이클 백트래킹, 조합/순열 생성.

🐍 Python

🟦 C++

이진 탐색 (Binary Search) 빈출

개념: 이미 정렬되어 있는 리스트에서 탐색 범위를 반씩 줄여가며 데이터를 찾아냅니다 ($O(\log N)$).

💡 키워드: 데이터 범위가 매우 클 때 ($N \ge 10,000,000$), 파라메트릭 서치.

🐍 Python
def binary_search(array, target, start, end):
    while start <= end:
        mid = (start + end) // 2
        if array[mid] == target: return mid
        elif array[mid] > target: end = mid - 1
        else: start = mid + 1
    return None
🟦 C++

3. 심화 그래프 알고리즘 (Advanced Graph)

다익스트라 (Dijkstra) 심화

개념: 하나의 시작 노드에서 다른 모든 노드까지의 최단 경로를 구합니다 (음수 가중치 없음).

💡 키워드: 가중치 그래프 최단 경로, 최소 비용 도로 탐색.

🐍 Python
import heapq
def dijkstra(start, graph, distance):
    q = []
    heapq.heappush(q, (0, start))
    distance[start] = 0
    while q:
        dist, now = heapq.heappop(q)
        if distance[now] < dist: continue
        for nxt, nxt_dist in graph[now]:
            cost = dist + nxt_dist
            if cost < distance[nxt]:
                distance[nxt] = cost
                heapq.heappush(q, (cost, nxt))
🟦 C++
#include <queue>
#include <vector>
#define INF 1e9

void dijkstra(int start, const std::vector<std::vector<std::pair<int, int>>>& graph, std::vector<int>& distance) {
    std::priority_queue<std::pair<int, int>, std::vector<std::pair<int, int>>, std::greater<std::pair<int, int>>> pq;
    pq.push({0, start}); distance[start] = 0;
    while (!pq.empty()) {
        auto [dist, now] = pq.top(); pq.pop();
        if (distance[now] < dist) continue;
        for (auto [next_node, next_dist] : graph[now]) {
            int cost = dist + next_dist;
            if (cost < distance[next_node]) {
                distance[next_node] = cost; pq.push({cost, next_node});
            }
        }
    }
}

플로이드-워셜 (Floyd-Warshall) 심화

개념: 모든 노드 쌍 간의 최단 경로를 한 번에 구합니다 ($O(N^3)$).

💡 키워드: $N \le 500$으로 작을 때, 모든 정점 간 최단거리 갱신.

🐍 Python
for k in range(1, n + 1):
    for a in range(1, n + 1):
        for b in range(1, n + 1):
            graph[a][b] = min(graph[a][b], graph[a][k] + graph[k][b])
🟦 C++
#include <algorithm>

    for (int a = 1; a <= n; ++a) {
        for (int b = 1; b <= n; ++b) {

        }
    }
}

유니온 파인드 (Union-Find) 심화

개념: 여러 원소 중 두 원소가 같은 집합에 속해 있는지 확인하고 합치는 연산입니다.

💡 키워드: 그래프 내의 사이클 존재 판별, 관계 네트워크 확인.

🐍 Python
def find_parent(parent, x):
    if parent[x] != x:
        parent[x] = find_parent(parent, parent[x])
    return parent[x]

def union_parent(parent, a, b):
    a = find_parent(parent, a)
    b = find_parent(parent, b)
    if a < b: parent[b] = a
    else: parent[a] = b
🟦 C++
#include <vector>

int findParent(std::vector<int>& parent, int x) {
    if (parent[x] != x) parent[x] = findParent(parent, parent[x]);
    return parent[x];
}

void unionParent(std::vector<int>& parent, int a, int b) {
    a = findParent(parent, a); b = findParent(parent, b);
    if (a < b) parent[b] = a;
    else parent[a] = b;
}

크루스칼 (Kruskal) 심화

개념: 비용 기준으로 간선을 정렬한 뒤, 사이클이 없을 때만 연결하여 MST를 구합니다.

💡 키워드: 최소 비용 도로 건설, 최소 신장 트리(MST) 구성.

🐍 Python
edges.sort()
for cost, a, b in edges:
    if find_parent(parent, a) != find_parent(parent, b):
        union_parent(parent, a, b)
        total_cost += cost
🟦 C++
#include <algorithm>
#include <tuple>

std::sort(edges.begin(), edges.end()); // cost 기준 정렬

for (const auto& edge : edges) {

4. 문제 해결 전략 및 패러다임 (Paradigm)

그리디 (Greedy) 전략

🐍 Python
meetings.sort(key=lambda x: (x[1], x[0]))

for start, end in meetings:

        last_end = end

투 포인터 (Two Pointers) 전략

개념: 두 개의 포인터를 대칭 혹은 동일 방향으로 움직여 구간 합 등을 O(N)에 탐색합니다.

💡 키워드: 연속된 수열의 합, 특정 구간 만족 여부 판별.

🐍 Python
current_sum, end, count = 0, 0, 0
for start in range(n):
    while current_sum < target and end < n:
        current_sum += arr[end]
        end += 1
    if current_sum == target: count += 1
    current_sum -= arr[start]
🟦 C++
int current_sum = 0, end = 0, count = 0;
for(int start = 0; start < n; ++start) {
    while(current_sum < target && end < n) {
        current_sum += arr[end++];
    }
    if(current_sum == target) count++;
    current_sum -= arr[start];
}

동적 계획법 (DP) 전략

개념: 계산된 하위 문제 값을 메모하여 중복 연산을 회피하고 상위 문제를 해결합니다.

💡 키워드: 최적화/가짓수 구하기, 이전의 최적 선택이 현재에 누적.

🐍 Python
dp = [0] * (n + 1)
dp[1], dp[2] = 1, 1
for i in range(3, n + 1):
    dp[i] = dp[i-1] + dp[i-2]
🟦 C++
#include <vector>

std::vector<int> dp(n + 1, 0);
dp[1] = 1; dp[2] = 1;
for(int i = 3; i <= n; ++i) {
    dp[i] = dp[i-1] + dp[i-2];
}

구현 / 시뮬레이션 전략

개념: 별도의 알고리즘 대신, 문제의 규칙을 효율적이고 세밀하게 소스코드로 옮깁니다.

💡 키워드: 행렬 회전/대칭, 방향 벡터(dx, dy) 활용, 조건 탐색.

🐍 Python
# 90도 시계방향 회전
def rotate_90(matrix):
    return [list(row) for row in zip(*matrix[::-1])]
🟦 C++
#include <vector>

std::vector<std::vector<int>> rotate90(const std::vector<std::vector<int>>& mat) {
    int n = mat.size();
    std::vector<std::vector<int>> res(n, std::vector<int>(n));
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            res[j][n - 1 - i] = mat[i][j];
        }
    }
    return res;
}
💡 코테 문제 풀 때 유용한 '치트키' 판단법
  • 입력 제한이 1억(100,000,000) 이상이다? → 높은 확률로 이진 탐색이나 수학적 규칙(지수/로그) 찾기 문제.
  • "가장 짧은 거리/최소 횟수"를 구하는데 가중치가 없다? → 무조건 BFS.
  • "경로의 수"나 "모든 경우의 수"를 구하는데 $N$이 작다? → DFS / 백트래킹.
  • 이미 구한 값이 다음 단계에 그대로 쓰인다? → DP (점화식 세우기).

16 대표 알고리즘 5선 개념 & 핵심 카드

코딩 테스트 및 알고리즘 대회에서 빈출되는 5가지 핵심 알고리즘 유형을 선별하여, 필수 기초 개념 설명과 함께 검증된 대표 문제 풀이 코드를 카드로 정리했습니다.

1. 구현 / 시뮬레이션 (Simulation) 빈출

개념: 문제에서 요구하는 조건과 규칙들을 빠짐없이 파악하고, 이를 정확하고 효율적인 코드로 그대로 재현하는 유형입니다. 주로 2차원 격자판 탐색, 방향 이동, 조건 제어 등이 빈번하게 출제됩니다.

💡 핵심 개념: 2차원 배열 제어, 시뮬레이션 루프, 방향 벡터(dx, dy)를 이용한 경계선 및 장애물 탐색.

⭐ 대표 문제: [CodeUp 6098] 성실한 개미

🐍 Python 예제 코드
# 10x10 격자판 입력받기 (공백 구분)
board = [list(map(int, input().split())) for _ in range(10)]

# 개미의 초기 위치 (2, 2) -> 인덱스로는 (1, 1)
x, y = 1, 1

while True:
    # 현재 위치를 방문 표시(9)로 변경
    board[x][y] = 9
    
    # 오른쪽 길(y+1)이 열려있거나(0) 먹이(2)가 있는 경우
    if board[x][y+1] == 0 or board[x][y+1] == 2:
        y += 1 # 오른쪽으로 이동
    # 오른쪽이 막혔고, 아래쪽 길(x+1)이 열려있거나 먹이가 있는 경우
    elif board[x+1][y] == 0 or board[x+1][y] == 2:
        x += 1 # 아래쪽으로 이동
    # 오른쪽과 아래쪽이 모두 벽(1)으로 막힌 경우
    else:
        break # 이동 불가, 종료
        
    # 이동한 자리에 먹이(2)를 찾았다면
    if board[x][y] == 2:
        board[x][y] = 9 # 먹이를 먹고 (9로 변경)
        break # 종료

# 최종 격자판 상태 출력
for row in board:
    print(*(row)) # 리스트 요소를 공백 구분하여 한 줄씩 출력

2. 완전 탐색 (Brute Force) / 재귀 (Recursion) 기초

개념: 컴퓨터의 빠른 연산 속도를 믿고 모든 가능한 가짓수를 남김없이 대입해보는 단순 명료한 해결책입니다. 동일한 작동 구조를 갖는 크기가 작은 서브 태스크를 반복 처리하기 위해 재귀 호출 방식을 즐겨 사용합니다.

💡 핵심 개념: 탐색 공간의 크기 파악, 재귀 기저 조건(Base Case) 설정, 함수 콜스택 이해.

⭐ 대표 문제: [CodeUp 1904] 두 수 사이의 홀수 출력하기

🐍 Python 예제 코드
# 시작 값(a)과 끝 값(b) 입력받기
a, b = map(int, input().split())

def print_odds(start, end):
    # 기저 조건: 시작 값이 끝 값을 초과하면 즉시 재귀 종료
    if start > end:
        return
    
    # 만약 현재 숫자가 홀수라면 공백을 두고 출력
    if start % 2 != 0:
        print(start, end=' ')
        
    # 다음 숫자를 판별하기 위해 자기 자신을 호출 (파라미터 증가)
    print_odds(start + 1, end)

# 함수 실행
print_odds(a, b)

3. 정렬 (Sorting) 기초

개념: 여러 데이터를 오름차순, 내림차순 또는 문제에서 정의한 임의의 우선순위에 입각하여 순서대로 배치하는 기법입니다. 효율적인 정렬을 통해 다음 연산의 탐색이나 검색 범위를 극적으로 좁힐 수 있습니다.

💡 핵심 개념: 기본 정렬 API, 람다 함수(lambda)를 이용한 다중 기준 정렬(Multi-key Sorting).

⭐ 대표 문제: [CodeUp 1420] 3등 찾기

🐍 Python 예제 코드
# 학생 수 입력
n = int(input())
students = []

# 학생 이름과 점수를 순차적으로 입력받기
for _ in range(n):
    name, score = input().split()
    students.append((name, int(score))) # 튜플 (이름, 점수) 형태로 저장

# 점수(x[1])를 기준으로 정렬하되, 내림차순(reverse=True)으로 정렬
# lambda x: x[1]은 튜플 데이터의 2번째 원소를 정렬 인자로 지정함을 뜻함
students.sort(key=lambda x: x[1], reverse=True)

# 정렬 결과에 따라 인덱스 2번(3위)에 속하는 학생의 이름(0번째 요소) 출력
print(students[2][0])

4. 탐색 및 이분 탐색 (Binary Search) 빈출

개념: 대규모 데이터 그룹에서 특정한 키값을 검색하는 방법입니다. 모든 요소를 처음부터 스캔하는 순차 탐색 대비, 정렬된 대상 내에서 비교할 때마다 남은 검색 공간을 1/2로 반감시켜 나가는 이분 탐색은 비교 불가능할 정도로 빠른 효율성을 갖습니다.

💡 핵심 개념: 시간 복잡도 O(log N), 시작점/끝점/중간점 포인터 관리, 결정 조건 수립.

⭐ 대표 문제: [CodeUp 2633] lower_bound (이분 탐색의 변형)

🐍 Python 예제 코드
# n개의 데이터 개수와 찾고자 하는 경계 기준값 k 입력
n, k = map(int, input().split())
arr = list(map(int, input().split()))

# 이분 탐색을 위한 시작점과 끝점 인덱스 설정
start = 0
end = n - 1
result = n + 1 # 만족하는 값이 없을 때를 대비한 디폴트 값

while start <= end:
    mid = (start + end) // 2 # 중간점 계산
    
    # 중간 지점의 값이 찾고자 하는 k보다 크거나 같은 경우
    if arr[mid] >= k:
        result = mid + 1 # 1-indexed 문제 조건에 맞추어 보정하여 기록
        end = mid - 1    # 더 왼쪽에 만족하는 최소 위치가 있는지 범위 좁히기
    else:
        start = mid + 1  # 더 큰 숫자가 밀집된 오른쪽 영역으로 탐색 시작점 이동

print(result)

5. 다이나믹 프로그래밍 (Dynamic Programming / 동적 계획법) 전략

개념: 복잡하고 큰 문제를 풀기 위해, 우선 작은 단위의 부분 문제들을 풀고 그 해를 캐싱(Memoization)합니다. 이후 동일한 부분 문제의 해가 필요할 때 캐시된 메모리 테이블에서 꺼내어 재사용(O(1))함으로써 연산의 반복을 완전 배제합니다.

💡 핵심 개념: 점화식 도출, 메모이제이션(Memoization) 테이블 구축, Bottom-Up(반복) vs Top-Down(재귀) 접근법.

⭐ 대표 문제: [CodeUp 2601] 피보나치 수열

🐍 Python 예제 코드
# 구하고자 하는 피보나치 수열의 N번째 항 순서 입력
n = int(input())

# 계산된 값을 저장해 둘 DP 테이블(리스트) 초기화 (직관적 인덱스를 위해 n+1 크기)
dp = [0] * (n + 1)

# 기본 초기 값(기저 상태) 설정
dp[1] = 1
if n >= 2:
    dp[2] = 1

# Bottom-Up 방식(반복 루프)으로 인덱스 3부터 점화식을 순차 연산
for i in range(3, n + 1):
    # 점화식: 현재 항의 값은 직전의 두 항의 합과 동일
    dp[i] = dp[i-1] + dp[i-2]

print(dp[n])
💡 알고리즘 핵심 요점정리
  • 구현 (Simulation): 인덱스 범위 초과 에러(IndexError)를 상시 유의하고 경계면 조건 체크를 정확히 설계해야 합니다.
  • 재귀 (Recursion): 반드시 종료가 보장되는 탈출 조건(Base Case)을 구조 상단부에 명시해야 스택 오버플로우가 나지 않습니다.
  • 정렬 (Sorting): 파이썬의 sort(key=lambda x: ...) 구문을 완전히 체득해두면 다차원 데이터 정렬 문제가 극도로 쉬워집니다.
  • 이분 탐색 (Binary Search): 탐색 대상이 반드시 이미 정렬되어 있을 때만 사용 가능한 고속 탐색법임을 기억하세요.
  • DP (Dynamic Programming): 중복 연산을 캐싱 공간에 기억해두는 '메모이제이션'을 통해 불필요한 서브 트리 탐색 비용을 혁신적으로 제거하는 접근법입니다.
