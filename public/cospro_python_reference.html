01 변수 대입 & 값 바꾸기 (Swap)

변수는 값을 담는 상자입니다. 3급에서 단골로 등장하는 기법 중 하나는 두 변수의 값을 서로 바꾸는 것(Swap)입니다.

기본 변수 대입

a = 10
b = 20
# a에는 10이, b에는 20이 저장됩니다.

두 변수의 값 서로 교환하기 (Swap)

파이썬에서는 임시 변수 없이 한 줄로 아주 간단하게 바꿀 수 있습니다.

a = 10
b = 20

# 두 값을 교환
a, b = b, a

print(a)  # 20
print(b)  # 10
3급 시험 Point 빈칸 채우기 문제에서 두 값을 바꾸어야 할 때 a, b = b, a 형태로 적거나, 임시 변수 temp를 사용해 temp = a; a = b; b = temp 형태로 바꾸는 코드가 매우 빈번히 출제됩니다.

02 필수 연산자 (특히 몫과 나머지)

덧셈, 뺄셈 외에도 3급 문제 해결의 핵심이 되는 나눗셈 연산자 3종 세트를 확실하게 구분해야 합니다.

연산자역할예시결과설명
/일반 나눗셈5 / 22.5소수점까지 구합니다.
//몫 연산자5 // 22소수점 아래를 버리고 정수 부분만 구합니다.
%나머지 연산자5 % 21나누고 남은 나머지를 구합니다. (홀짝/배수 판별에 필수!)
# 시간 계산 문제 예시 (초 -> 분/초)
total_seconds = 130
minutes = total_seconds // 60  # 2 (몫: 분)
seconds = total_seconds % 60   # 10 (나머지: 초)

print(minutes, "분", seconds, "초")  # 2 분 10 초

03 조건문 (if-else)

참과 거짓에 따라 코드의 흐름을 분기합니다. 3급에서는 조건의 경계(이상, 이하, 초과, 미만)를 올바르게 작성했는지가 핵심입니다.

기본 문법 구조

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

비교 및 논리 연산자

  • == (같다), != (다르다)
  • and (둘 다 참이어야 참), or (둘 중 하나만 참이어도 참), not (참을 거짓으로, 거짓을 참으로)
Warning 조건문에서는 들여쓰기(Indentation)가 올바르지 않으면 오류가 나거나 의도와 다르게 작동합니다. 빈칸 채우기나 한 줄 수정 문제를 볼 때 들여쓰기 위치를 유심히 확인하세요.

04 반복문 (for / range)

3급에서는 지정된 횟수만큼 반복하는 for 문과 range() 함수가 핵심입니다. range()의 범위 시작과 끝을 이해하는 것이 첫걸음입니다.

range() 범위 시각화

사용법생성되는 숫자 범위설명
range(5)0, 1, 2, 3, 40부터 시작해서 5 미만(4)까지 (총 5번 반복)
range(1, 6)1, 2, 3, 4, 51부터 시작해서 6 미만(5)까지
range(1, 6, 2)1, 3, 51부터 시작해서 2씩 건너뛰며 6 미만까지

반복문으로 더하기 예제

total = 0
for i in range(1, 6):
    total += i  # 1, 2, 3, 4, 5가 차례로 total에 누적해서 더해짐

print(total)  # 15

05 리스트 완전 정복 (기본 연산부터 응용까지)

리스트는 여러 개의 데이터를 순서대로 한 줄로 늘어놓은 상자 세트와 같습니다. COS Pro 3급과 코드업 문제의 절반 이상은 이 리스트를 얼마나 자유자재로 다룰 수 있는지를 묻습니다.

1. 리스트 인덱싱 & 원소 수정 (원하는 위치 가리키기)

파이썬은 첫 번째 칸을 0번 인덱스로 부르고, 마지막 칸을 -1번 인덱스로 쉽게 가리킬 수 있습니다.

arr = [10, 20, 30, 40]
# 인덱스:  0    1    2    3
# 음수:   -4   -3   -2   -1

print(arr[0])   # 10 (첫 번째 값)
print(arr[-1])  # 40 (마지막 값)

# 리스트 안의 값 수정하기
arr[1] = 99     # 1번 자리에 있던 20을 99로 교체
print(arr)      # [10, 99, 30, 40]

2. 리스트에 값 추가하고 삭제하기

리스트는 길이가 고정되어 있지 않으며, 아래의 메서드로 칸을 마음대로 늘리고 줄일 수 있습니다.

사용 코드역할예제 (arr = [1, 2]) 실행 결과
arr.append(값)맨 끝에 새로운 값을 추가합니다. (가장 많이 씀)arr.append(3) -> [1, 2, 3]
arr.insert(인덱스, 값)원하는 특정 위치에 값을 삽입합니다.arr.insert(0, 9) -> [9, 1, 2]
arr.pop()맨 끝에 있는 값을 지우면서 돌려줍니다.arr.pop() 실행 시 2 반환, [1]로 바뀜
arr.pop(인덱스)해당 인덱스 번호에 있는 값을 지우면서 돌려줍니다.arr.pop(0) 실행 시 1 반환, [2]로 바뀜
arr.remove(값)지정한 값을 찾아 첫 번째 매칭 대상을 삭제합니다.arr.remove(2) -> [1]

3. 리스트 자르기 (슬라이싱) & 뒤집기

리스트의 일부분만 잘라내어 새로운 리스트를 만들 수 있습니다. arr[시작:끝] 형태로 사용하며 끝 번호는 포함되지 않는다는 점이 핵심입니다.

arr = [10, 20, 30, 40, 50]

print(arr[0:3])   # [10, 20, 30] (인덱스 0, 1, 2번 값 추출)
print(arr[2:])    # [30, 40, 50] (인덱스 2번부터 끝까지)
print(arr[:2])    # [10, 20] (처음부터 인덱스 2번 앞까지)

# 리스트 뒤집기 (역순 배열 만들기)
reversed_arr = arr[::-1]
print(reversed_arr)  # [50, 40, 30, 20, 10]

4. 특정 값 검색하기 및 개수 세기

리스트 안에 특정 원소가 들어있는지 검사하거나, 총 몇 개가 있는지 세는 등 조건문 처리에 자주 사용됩니다.

colors = ["red", "blue", "red", "green"]

# 1. 포함 여부 확인 (in 연산자) -> True / False 반환
is_red_in = "red" in colors      # True
is_yellow_in = "yellow" in colors  # False

# 2. 특정 원소의 개수 세기 (.count)
red_count = colors.count("red")   # 2

# 3. 특정 원소의 위치 구하기 (.index)
blue_index = colors.index("blue") # 1 (가장 먼저 나오는 인덱스 반환)

5. 리스트 정렬하기

원소들을 크기 순(오름차순, 내림차순)으로 나열하는 법은 매우 빈번하게 사용됩니다.

numbers = [5, 2, 9, 1, 7]

# 방법 1: 원본 리스트 자체를 정렬해서 바꾸기 (.sort)
numbers.sort()
print(numbers)  # [1, 2, 5, 7, 9] (오름차순)

# 방법 2: 내림차순(큰 수부터) 정렬하기
numbers.sort(reverse=True)
print(numbers)  # [9, 7, 5, 2, 1]

# 방법 3: 원본은 그대로 두고, 정렬된 새로운 리스트 얻기 (sorted)
arr = [3, 1, 2]
new_arr = sorted(arr)
print(arr)      # [3, 1, 2] (원본 유지)
print(new_arr)  # [1, 2, 3] (새로운 정렬본)

6. 리스트 전체 탐색하기 (for문 조합)

리스트 안의 값들을 하나씩 꺼내 검사하는 필수적인 두 가지 방식입니다.

scores = [80, 90, 75]

# 방식 A: 값 자체를 순서대로 하나씩 꺼내오기 (값만 필요할 때)
for s in scores:
    if s >= 80:
        print(s, "합격")

# 방식 B: 인덱스 번호(0, 1, 2)를 순서대로 꺼내오기 (위치 정보나 수정이 필요할 때)
for i in range(len(scores)):
    if scores[i] >= 80:
        print(i, "번째 학생 합격")

7. 리스트 활용 코스프로 3급 빈출 문제 유형 (실전 예제)

실제 시험에서 빈칸 채우기나 한 줄 수정하기로 정말 자주 나오는 핵심 문제 상황들입니다. 코드를 눈으로 익혀두세요.

유형 1. 평균을 구하고 평균 이상인 학생 수 세기

def solution(scores):
    # 1. 평균 계산 (총합 / 개수)
    average = sum(scores) / len(scores)
    
    # 2. 평균 이상인 학생 수 세기
    count = 0
    for s in scores:
        if s >= average:
            count += 1
            
    return count

print(solution([50, 70, 80, 100]))  # 평균은 75 -> 75 이상은 80, 100 총 2명

sum()과 len()으로 평균을 먼저 구한 뒤, 리스트를 순회하며 개수(count)를 카운팅하는 전형적인 빈칸 유형입니다.

유형 2. 최댓값과 최솟값의 차이 구하기

def solution(arr):
    # 최댓값과 최솟값 구하기
    max_val = max(arr)
    min_val = min(arr)
    
    # 차이 계산
    result = max_val - min_val
    return result

print(solution([12, 5, 23, 45, 18]))  # 45 - 5 = 40 출력

주어진 점수 리스트에서 가장 큰 값과 가장 작은 값의 편차를 구하는 문제로, max()와 min() 함수의 적절한 활용을 묻습니다.

유형 3. 최고점과 최저점을 제외한 점수들의 평균

def solution(scores):
    # 전체 합에서 최댓값과 최솟값 빼기
    total = sum(scores) - max(scores) - min(scores)
    
    # 개수는 총 개수에서 2개를 빼줌
    count = len(scores) - 2
    
    return total / count

print(solution([90, 10, 80, 100, 70]))  # 10과 100을 제외한 90, 80, 70의 평균 = 80

체육 대회 심사 점수 등에서 공정한 평가를 위해 최고/최저 점수를 제외하고 평균을 산출하는 단골 유형입니다.

유형 4. 티셔츠 사이즈별 필요한 개수 세기

def solution(requests):
    # 사이즈 목록: S, M, L 순서
    # 각각의 개수를 담을 리스트 [S개수, M개수, L개수]
    answer = [0, 0, 0]
    
    for req in requests:
        if req == "S":
            answer[0] += 1
        elif req == "M":
            answer[1] += 1
        elif req == "L":
            answer[2] += 1
            
    return answer

print(solution(["S", "L", "S", "M", "L", "L"]))  # [2, 1, 3]

문자열로 된 리스트를 읽어, 조건에 맞추어 누적값 리스트의 해당 인덱스 자리에 값을 카운팅 해나가는 기법입니다.

06 함수와 return

함수는 특정 작업을 수행하는 작은 프로그램입니다. 입력값(매개변수)을 받아 처리하고, return을 통해 결과를 돌려줍니다.

함수 기본 형태

def add(x, y):
    result = x + y
    return result  # 함수가 최종적으로 돌려주는 값

# 함수 호출 및 결과 출력
answer = add(3, 5)
print(answer)  # 8
자주 하는 실수 함수가 결과를 반환해야 하는데 return을 빼먹으면, 함수는 자동으로 None을 반환하게 됩니다. 채점 결과가 None이 나온다면 return 키워드를 빠뜨렸는지 확인하세요.

07 [패턴 1] 합계 & 개수 세기

조건을 주고 "조건에 만족하는 원소들의 합"이나 "조건에 만족하는 원소들의 개수"를 세는 패턴입니다.

조건에 맞는 원소들의 합 구하기

scores = [85, 60, 90, 70]
total = 0

for s in scores:
    if s >= 80:  # 80점 이상인 경우만
        total += s

print(total)  # 175 (85 + 90)

합계를 저장할 변수 total을 0으로 초기화한 뒤 조건에 맞을 때만 누적합을 구합니다.

조건에 맞는 원소 개수 세기

scores = [85, 60, 90, 70]
count = 0

for s in scores:
    if s >= 80:  # 80점 이상인 경우만
        count += 1

print(count)  # 2 (85, 90 두 개)

개수를 저장할 변수 count를 0으로 설정하고, 조건을 만족하면 +1을 해줍니다.

08 [패턴 2] 최댓값·최솟값 찾기

리스트 안에 든 숫자 중 가장 큰 값이나 가장 작은 값을 구하는 패턴입니다. 내장함수(max, min)를 쓸 수도 있지만, 직접 반복문으로 구현하는 것도 중요합니다.

최댓값 직접 구하기

arr = [3, 7, 2, 9, 5]
max_val = arr[0]  # 첫 번째 값으로 초기화

for num in arr:
    if num > max_val:
        max_val = num  # 더 큰 값 발견 시 갱신

print(max_val)  # 9

최댓값을 리스트의 첫 원소로 두고, 더 큰 값이 나타나면 갱신합니다.

최솟값 직접 구하기

arr = [3, 7, 2, 9, 5]
min_val = arr[0]  # 첫 번째 값으로 초기화

for num in arr:
    if num < min_val:
        min_val = num  # 더 작은 값 발견 시 갱신

print(min_val)  # 2

최솟값을 리스트의 첫 원소로 두고, 더 작은 값이 나타나면 갱신합니다.

09 [패턴 3] 각 자릿수 분리하기 (몫과 나머지 활용)

어떤 숫자의 일의 자리 숫자를 구하거나, 각 자리 숫자의 합을 구해야 할 때 매우 유용한 수학적 공식 패턴입니다.

1. 일의 자리 숫자 구하기 (n % 10)

어떤 숫자를 10으로 나눈 나머지는 항상 그 숫자의 가장 오른쪽 자릿수(일의 자리)가 됩니다.
예: 123 % 10 -> 3

2. 마지막 자릿수 제거하기 (n // 10)

어떤 숫자를 10으로 나눈 몫은 가장 오른쪽 자릿수를 제외한 나머지 숫자가 됩니다.
예: 123 // 10 -> 12

각 자릿수 합계 구하기 예제

n = 1234
digit_sum = 0

while n > 0:
    digit_sum += n % 10  # 1. 일의 자리 숫자를 꺼내서 더하기
    n = n // 10          # 2. 일의 자리를 지우기 (n이 점차 줄어들어 0이 됨)

print(digit_sum)  # 10 (4 + 3 + 2 + 1)

10 [패턴 4] 홀짝 & 배수 판별

어떤 수가 짝수인지 홀수인지, 또는 특정 수의 배수인지 판별할 때는 나머지 연산자 %를 활용합니다.

홀수/짝수 판별

num = 7

if num % 2 == 0:
    print("짝수")
else:
    print("홀수")

배수 판별 (예: 3의 배수 판별)

어떤 수 num을 N으로 나눈 나머지가 0이면 그 수는 N의 배수입니다.

num = 15

if num % 3 == 0:
    print("3의 배수입니다.")  # 출력됨

11 [패턴 5] 리스트 내 원소 교환 (Swap)

리스트 안에 든 특정 두 원소의 위치를 바꾸는 패턴입니다. 정렬 알고리즘이나 역순 정렬을 손으로 구현할 때 자주 쓰입니다.

arr = [10, 20, 30, 40]

# 0번 인덱스와 2번 인덱스의 값을 바꿉니다.
# arr[0] (10)과 arr[2] (30) 교환
arr[0], arr[2] = arr[2], arr[0]

print(arr)  # [30, 20, 10, 40]

12 시험에서 자주 실수하는 체크리스트

  • 0-기반 인덱스: 컴퓨터는 숫자를 0부터 셉니다. '3번째 값'을 찾으라고 하면 인덱스는 2여야 합니다 (arr[2]).
  • 범위 미만(Stop값): range(1, 10)은 10을 포함하지 않는 1부터 9까지의 숫자만 만듭니다.
  • 일반 나눗셈 vs 정수 나눗셈: 소수가 포함된 결과를 원하면 /를, 소수가 없는 몫을 구하려면 //를 사용하세요.
  • 비교연산자 ==: 두 값이 같은지 비교할 때는 =(대입)이 아니라 반드시 ==를 사용해야 합니다.
  • return과 print의 차이: 채점용 함수 내에서는 print()로 출력만 하면 안 되고, 반드시 return을 통해 값을 결과로 보내줘야 합니다.
