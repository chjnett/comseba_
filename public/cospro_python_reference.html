01 변수·입출력·자료형

입출력 — 코스프로 채점 환경의 기본

# 한 줄에 정수 하나
n = int(input())

# 한 줄에 공백으로 구분된 정수 여러 개
a, b = map(int, input().split())

# 한 줄에 공백 구분 정수 N개 → 리스트로
arr = list(map(int, input().split()))

# 함수형 문제(채점 함수만 작성)는 input() 없이
# solution(매개변수) 형태로 바로 주어지는 경우가 많음

Tip 코스프로는 보통 함수 안에 코드를 작성하는 함수형 문제가 많습니다. input()으로 직접 입력받는 형식인지, def solution(...) 안에 로직만 채우는 형식인지 문제 설명을 먼저 확인하세요.

05 딕셔너리 & 집합

딕셔너리 — "개수 세기" 문제의 핵심 도구

cnt = {}
for ch in 'banana':
    cnt[ch] = cnt.get(ch, 0) + 1
# {'b':1, 'a':3, 'n':2}

for key, value in cnt.items():
    print(key, value)

if 'a' in cnt:        # 키 존재 여부 확인 (O(1)로 빠름)

06 함수와 재귀

def add(a, b=0):       # b는 기본값(default argument)
    return a + b

add(3)             # 3  (b는 기본값 0 사용)
add(3, 5)          # 8

재귀 함수 — 코스프로 3급 단골 유형

def factorial(n):
    if n <= 1:          # 종료 조건(base case) — 반드시 필요
        return 1
    return n * factorial(n - 1)

factorial(5)   # 120
Tip 재귀 함수를 짤 때는 ① 종료 조건(언제 멈추는가), ② 더 작은 문제로 줄이는 식(n → n-1), 이 두 가지만 정확히 정의하면 됩니다. 종료 조건을 빼먹으면 RecursionError가 발생합니다.

07 문자열 유형 정리

회문(팰린드롬) 판별 단골

def is_palindrome(s):
    return s == s[::-1]

슬라이싱으로 뒤집은 문자열과 원본을 그대로 비교하는 게 가장 빠른 방법입니다.

아나그램(애너그램) 판별

def is_anagram(a, b):
    return sorted(a) == sorted(b)

두 문자열을 정렬해서 같은지 비교하면 글자 구성이 같은지 바로 알 수 있습니다.

문자 빈도수 세기

cnt = {}
for ch in s:
    cnt[ch] = cnt.get(ch,0)+1

딕셔너리로 카운팅 → "가장 많이 등장한 문자" 같은 후속 질문에 바로 활용 가능.

문자열 압축/패턴 찾기

# 연속된 같은 문자 개수 세기
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j]==s[i]:
        j += 1
    # s[i]가 (j-i)번 연속됨
    i = j

"두 개의 포인터(i, j)로 같은 구간의 끝을 찾는다"는 패턴은 문자열 압축 문제의 기본 틀입니다.

08 배열/리스트 유형 정리

누적합(Prefix Sum) 단골

prefix = [0] * (len(arr)+1)
for i in range(len(arr)):
    prefix[i+1] = prefix[i] + arr[i]
# 구간 [l,r) 합 = prefix[r] - prefix[l]

"특정 구간의 합을 여러 번 물어보는" 문제에서 매번 더하면 느립니다. 미리 누적합을 만들어두면 구간 합을 O(1)에 구합니다.

투 포인터(Two Pointer)

l, r = 0, len(arr)-1
while l < r:
    if arr[l]+arr[r] == target:
        break
    elif arr[l]+arr[r] < target:
        l += 1
    else:
        r -= 1

정렬된 배열에서 "합이 특정 값이 되는 두 수 찾기" 같은 문제를 O(N)에 풉니다.

슬라이딩 윈도우

# 길이 k인 구간의 최대 합
window = sum(arr[:k])
best = window
for i in range(k, len(arr)):
    window += arr[i] - arr[i-k]
    best = max(best, window)

구간이 한 칸씩 이동할 때 "빠지는 값 빼고 들어오는 값 더하기"만 하면 매번 새로 합을 구할 필요가 없습니다.

2차원 리스트 순회

for i in range(n):
    for j in range(m):
        print(grid[i][j])

행렬/격자 문제는 거의 항상 이중 for문이 기본 틀이며, 상/하/좌/우 이동은 dx,dy 방향 벡터 리스트로 처리하면 코드가 짧아집니다.

09 시뮬레이션 유형 정리

"문제에서 설명한 규칙을 그대로, 단계별로 코드로 옮기면 풀리는" 유형입니다. 코스프로 2~3급에서 비중이 큽니다.

1. 상태(State) 정의하기

위치, 방향, 점수, 남은 횟수 등 "지금 무엇이 바뀌고 있는지"를 변수로 먼저 정의합니다.

2. 한 단계(틱)의 동작을 함수/블록으로 분리

"한 번 이동", "한 번 회전"처럼 반복되는 동작 하나를 명확한 단위로 쪼개면 버그가 줄어듭니다.

3. 반복 조건과 종료 조건을 분리해서 작성

"몇 번 반복하는지"와 "언제 멈추는지"를 헷갈리지 않게 따로 적어두고 코드로 옮깁니다.

# 방향 벡터를 미리 정의해두는 패턴 (상,하,좌,우)
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

for d in range(4):
    nx, ny = x+dx[d], y+dy[d]
    if 0 <= nx < n and 0 <= ny < m:   # 범위(경계) 체크 필수
        print(nx, ny)
자주 하는 실수 격자/배열을 이동하는 시뮬레이션에서 경계값 체크를 빼먹는 것이 가장 흔한 실수입니다. 이동 후 인덱스가 배열 범위를 벗어나지 않는지 항상 먼저 확인하세요.

10 탐색·정렬 유형 정리

완전탐색(Brute Force)

# 가능한 모든 두 수의 조합 확인
for i in range(len(arr)):
    for j in range(i+1, len(arr)):
        if arr[i] + arr[j] == target:
            print(i, j)

# 순열/조합이 필요할 때는 itertools 사용
from itertools import permutations, combinations
list(permutations([1,2,3], 2))   # 순서 있는 2개 뽑기
list(combinations([1,2,3], 2))   # 순서 없는 2개 뽑기

정렬 — key를 활용한 기준 정렬

students = [('kim',90), ('lee',85)]

# 점수 기준 내림차순
sorted(students, key=lambda x: x[1], reverse=True)

# 점수 내림차순, 같으면 이름 오름차순 (다중 기준)
sorted(students, key=lambda x: (-x[1], x[0]))

이분 탐색(Binary Search)

def binary_search(arr, target):
    lo, hi = 0, len(arr)-1
    while lo <= hi:
        mid = (lo+hi)//2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid+1
        else:
            hi = mid-1
    return -1          # 못 찾음

# 표준 라이브러리로 간단히 — 정렬된 배열 전용
import bisect
bisect.bisect_left(arr, target)
Tip 이분 탐색은 배열이 정렬되어 있을 때만 쓸 수 있습니다. "정렬 후 이분탐색"은 한 세트로 묶어 기억해두세요.

11 이 레벨에서 나오는 알고리즘 정리

알고리즘한 줄 설명시간복잡도
완전탐색가능한 모든 경우를 다 확인대개 O(N²)~O(N!) — 입력 크기 작을 때만
그리디(탐욕법)매 순간 가장 좋아 보이는 선택을 함O(N) ~ O(N log N)
정렬 후 처리먼저 정렬하면 문제가 쉬워지는 패턴O(N log N)
이분 탐색정렬된 데이터에서 절반씩 줄여가며 탐색O(log N)
두 포인터 / 슬라이딩 윈도우구간을 양 끝/한쪽씩 옮기며 탐색O(N)
재귀 / 간단한 DP(메모이제이션)큰 문제를 같은 모양의 작은 문제로 나눠서 풀기문제별로 다름
BFS/DFS 기초그래프·격자를 너비/깊이 우선으로 탐색 (3급 후반~상위 단계에 등장)O(N+E)

그리디 예시 — 동전 거스름돈

coins = [500, 100, 50, 10]
amount = 1260
count = 0
for c in coins:
    count += amount // c
    amount %= c
print(count)   # 가장 큰 동전부터 최대한 많이 사용

간단한 DP 예시 — 피보나치 (메모이제이션)

memo = {}
def fib(n):
    if n <= 1:
        return n
    if n in memo:        # 이미 계산했으면 재사용
        return memo[n]
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]

단순 재귀로 피보나치를 풀면 같은 값을 계속 다시 계산해서 느려집니다. memo 딕셔너리에 결과를 저장해두고 재사용하는 것이 "메모이제이션"이며, DP의 가장 쉬운 형태입니다.

        dfs(x+dx[d], y+dy[d])

12 자주 하는 실수 체크리스트

  • 2차원 리스트를 [[0]*m]*n으로 만들어서 모든 줄이 같은 객체를 참조하는 실수
  • 인덱스가 범위를 벗어나는지(경계 체크) 확인하지 않고 배열에 접근
  • 문자열을 인덱스로 직접 수정하려는 시도 (문자열은 불변 — list로 바꿔서 작업)
  • 정렬되지 않은 배열에 이분 탐색을 적용
  • arr.sort()(반환값 없음)와 sorted(arr)(새 리스트 반환)를 혼동
  • 재귀 함수에 종료 조건(base case)을 빼먹어 무한 재귀 발생
  • 나눗셈에서 /(실수 나눗셈)와 //(정수 나눗셈)를 혼동
  • 입력 형식(한 줄 정수 vs 공백 구분 여러 값 vs 함수형 매개변수)을 잘못 파악
